| 前置文档 | [ESP32-S3 N16R8 主控选型与开发板说明](./2-esp32-s3-n16r8-platform.md) |

本文记录 Desk Gateway 增加两颗 ToF（Time of Flight）距离传感器的硬件与软件方案。模块实物已经确认，固件采集和 Web 显示链路已经实现；**尚未完成接线、校准与真机验收，当前结果不得用于运动控制**。

---

## 1. 方案结论

| 位置 | 选型 | 预期芯片 | 用途 | 结论 |
|---|---|---|---|---|
| 桌面右侧 | TOF050C | VL6180X | 测量桌面右侧与墙面之间约 5–10 cm 的距离 | 采用 |
| 桌面下方 | TOF400C | VL53L1X | 测量传感器到地面的距离，换算桌面垂直高度 | 采用，须先完成全行程验收 |

TOF400C 的标称 4 m 量程覆盖桌子约 129 cm 的最大高度，但商品标称量程不等于所有地面和
环境光条件下的可靠量程；TOF400C 必须先通过 64–129 cm 全行程、不同地面材质和环境光
测试，才能成为档位闭环和最高安全高度的输入。

`TOF050C`、`TOF400C` 是模块名称，不是 ST 官方器件型号。实物正反面已经确认两块板均引出
`VIN/GND/SDA/SCL/INT/SHUT`，TOF400C 正面标注 `TOF400C-VL53L1X`；TOF050C 按资料和
初始化寄存器使用 `VL6180X` 驱动，仍需在真机读取 Model ID 作为最终确认。

---

## 2. 测量目标

### 2.1 右侧短距离

TOF050C 水平安装在桌面右侧，朝向右侧墙面：

- 重点测量范围：约 `0–100 mm`。
- 用途：识别桌面右侧过于接近书架或障碍物的情况。
- 传感器光轴应尽量垂直于目标表面，避免只照到墙面边缘或其他物体。
- 极近距离、无回波或量程状态异常不能直接解释为“距离安全”。具体故障策略必须基于实物数据确定。

### 2.2 垂直高度

TOF400C 安装在桌板下方并垂直朝向地面：

```text
桌面实际高度
  = 传感器到地面的测量距离
  + 桌面上表面到传感器光学中心的固定安装偏移
```

约束：

1. 传感器视场内不能长期出现桌腿、线缆、主机箱、椅子、脚或其他遮挡物。
2. 固定安装后必须测量安装偏移，不能直接把传感器读数当作桌面高度。
3. 现有控制盒高度仍作为主要业务数据；ToF 高度先作为独立校验数据，完成全行程验证后再决定是否参与安全上限判断。

## 3. GPIO 与接线方案

### 3.1 已占用和禁止使用的 GPIO

| GPIO | 当前用途 / 约束 |
|---|---|
| GPIO4 / GPIO5 | 控制盒侧 CLK / DAT |
| GPIO6 / GPIO7 | 原厂控制面板侧 CLK / DAT |
| GPIO19 / GPIO20 | ESP32-S3 原生 USB |
| GPIO35 / GPIO36 / GPIO37 | N16R8 Flash / Octal PSRAM 内部占用，禁止外接 |
| GPIO43 / GPIO44 | UART0 调试 |
| GPIO48 | 板载 WS2812 RGB |

### 3.2 ToF 总线分配

两颗传感器共享一组新的硬件 I²C 总线：

| ESP32-S3 | TOF050C | TOF400C | 说明 |
|---|---|---|---|
| 3V3 | VCC | VCC | 使用 ESP32 开发板 3.3V |
| GND | GND | GND | 共地 |
| GPIO10 | SCL | SCL | 共享 I²C 时钟 |
| GPIO11 | SDA | SDA | 共享 I²C 数据 |
| GPIO12 | XSHUT / SHUT | — | 单独控制 TOF050C 启停与地址初始化 |
| GPIO13 | — | XSHUT / SHUT | 单独控制 TOF400C 启停与地址初始化 |
| 不接 | GPIO1 / INT | GPIO1 / INT | 第一版采用轮询，不使用中断 |

供电要求：

- 两个模块都由 ESP32 开发板的 `3V3/GND` 供电。
- **不得使用升降桌 RJ45 红线的 3.3V 为 ToF 模块供电。**
- 到货后先确认模块是否自带稳压、I²C 电平转换和上拉电阻，不按商品标题猜测电气参数。
- 两块模块的 I²C 上拉会并联。接线后应断电测量 `SCL/SDA` 到 `3V3` 的等效阻值，确认没有形成过强上拉。

## 4. I²C 地址冲突处理

VL6180X 和 VL53L1X 常用的 7-bit I²C 默认地址均为 `0x29`（文档中也可能以 8-bit
写地址 `0x52` 表示），两颗模块不能以默认地址同时工作。

每次 ESP32 启动时按以下顺序初始化：

1. GPIO12、GPIO13 拉低，使两颗传感器都保持关断。
2. 只释放 TOF050C 的 XSHUT，等待启动完成。
3. 通过默认地址 `0x29` 连接 TOF050C，并将其运行地址改为 `0x30`。
4. 释放 TOF400C 的 XSHUT，等待启动完成。
5. 通过默认地址 `0x29` 连接 TOF400C。
6. 分别读取 `0x30` 和 `0x29` 的 Model ID，确认两颗传感器在线。

地址修改通常不会跨掉电保存，因此每次启动都必须重复以上过程。任一步失败时应保持距离数据无效，不能生成虚假的安全距离或高度。

## 5. 软件接入计划

独立组件 `components/sensors/desk_tof` 负责双地址初始化、采样、三点中值滤波和过期失效，
具体芯片驱动不写入 `desk_core` 或 `yourdesk_v1`：

```text
TOF050C / VL6180X ─┐
                    ├─ desk_tof ── 只读距离状态 ── REST / Web
TOF400C / VL53L1X ─┘
```

当前 REST 输出的最小状态：

| 字段 | 含义 |
|---|---|
| `right_gap_mm` | 桌面右侧到墙面的距离 |
| `right_gap_known` | 右侧距离是否有效且未过期 |
| `tof_height_mm` | 加入安装偏移后的桌面高度 |
| `tof_height_known` | ToF 高度是否有效且未过期 |

当前已经完成：

1. I²C、SHUT 上电排序以及 TOF050C 地址切换。
2. 有效量程状态过滤、三点中值滤波和 1 秒数据过期失效。
3. REST 状态字段 `tof_height_mm/tof_height_known/right_gap_mm/right_gap_known`。
4. Web 卡片实时显示桌面高度和“桌面右侧 → 墙面”间距。
5. 采样数据不进入 `desk_core` 的运动、档位或安全策略。

待真机完成：安装偏移校准、连续冷启动、全行程和不同材质验收；通过后再讨论安全策略。

## 6. 安全策略边界

### 6.1 右侧防碰撞

后续允许配置最小安全间距。只有连续多个有效样本都低于阈值时，才停止或禁止继续上升；下降和 STOP 必须始终可用。

无回波、超量程、过期数据和传感器掉线需要单独标记。具体是否按“危险接近”处理，要根据 TOF050C 在极近距离下的真机输出决定，不能在硬件到货前写死。

### 6.2 高度校验

- 当前控制盒 digit 高度解析已停用，TOF400C 是候选运行时高度源。
- 初次校准必须使用人工卷尺或可靠参考高度建立安装偏移，不能用旧 digit 缓存自动校准。
- ToF 高度连续稳定后才能用于档位闭环和安全判断，单次跳变不能触发运动或覆盖持久化校准值。
- 传感器无效、掉线或数据过期时，立即退出高度闭环和上升限高；手动 STOP 与下降仍须可用。
- 童锁、STOP 和现有来源权限的优先级不因增加 ToF 而改变。

## 7. 到货检查清单

收到模块后，编码前先完成：

- [ ] 拍摄模块正反面和芯片丝印。
- [ ] 上电读取 TOF050C 与 TOF400C 的 Model ID，最终确认实际芯片型号。
- [ ] 确认两个模块都引出 XSHUT / SHUT。
- [ ] 确认模块允许使用 3.3V 供电和 3.3V I²C 电平。
- [ ] 断电测量 VCC、GND、SCL、SDA、XSHUT 的连通关系和上拉阻值。
- [ ] 单独连接每颗模块，确认默认地址及基础测距。
- [ ] 再连接双模块，验证 XSHUT 分配地址流程。
- [ ] 确认模块安装位置不会遮挡 USB、现有 RJ45 总线或 ESP32 天线。

## 8. 真机验收标准

### 8.1 基础验收

- 两颗传感器连续冷启动 20 次均能稳定工作在 `0x30`、`0x29`。
- 传感器初始化失败不会影响 Web、REST、BLE、原厂总线和 STOP。
- 拔掉任意一颗传感器后，固件报告该传感器离线且不产生错误运动命令。

### 8.2 TOF050C

- 在预期的 10 cm 及更短距离内记录不同目标材质的有效率和抖动。
- 覆盖极近距离、目标倾斜、目标边缘和无目标情况。
- 安全阈值测试中不存在把无效数据误判为“距离充足”的情况。

### 8.3 TOF400C

- 覆盖桌子约 64–129 cm 全行程。
- 分别测试浅色地面、深色地面、地垫以及不同环境光。
- 完成安装偏移校准后，桌面高度显示误差目标为不超过 `±10 mm`。
- 升降过程中高度变化方向正确，不出现长时间冻结、反向跳变或单帧大幅跳变。

只有通过以上验收，ToF 数据才可以从“显示和日志”升级为“运动安全输入”。
