# 用逻辑分析仪破解升降桌协议

| 项 | 内容 |
|---|---|
| 文档编号 | DG-CAP-001 |
| 版本 | 0.1 |
| 日期 | 2026-08-05 |
| 状态 | 草案 |
| 对应阶段 | Phase 0（协议逆向） |
| 前置文档 | [需求文档](./0-requirements.md) |

本文说明如何在 **不断开原厂面板与主机正常连接** 的前提下，用逻辑分析仪旁路抓取 `CLK` / `DAT`，为后续 ESP32 模拟发令提供依据。

---

## 1. 目标与边界

### 1.1 目标

1. 确认物理层：电压、地、CLK/DAT 与 RJ45 针脚对应关系。
2. 确认时序：谁产生 CLK、采样沿、比特率量级、帧边界。
3. 抓到可复现的操作波形：静置、升降、档位、保存。
4. 产出可交给 Phase 1 使用的材料：`.sr` 抓包、针脚表、初步命令假设。

### 1.2 不做

- 不在未知电压时主动向总线灌电平。
- 不把 RJ45 插进电脑网口 / 交换机 / USB 网卡。
- 本文不产出最终命令表定稿（定稿进《协议逆向笔记》）。

---

## 2. 安全规则（先读）

1. **先断电，再接线；先测电压，再接分析仪。**
2. 普通 USB 逻辑分析仪通常只耐受 **3.3V / 5V**。面板丝印有 `3.3V`，但仍需实测确认；若出现 12V/24V，必须先分压或示波器确认，禁止直连分析仪。
3. 分析仪 **只接 GND / CLK / DAT**。不要把分析仪的电源脚接到面板 `3.3V`。
4. 面板继续由桌子主机供电；分析仪只旁路监听。
5. 探针固定好再操作升降，避免手持探针短路。

---

## 3. 设备清单

| 设备 | 用途 | 备注 |
|---|---|---|
| 数字万用表 | 导通、电压 | 必备 |
| USB 逻辑分析仪（≥ 8 通道更佳） | 抓 CLK/DAT | 输入需支持 3.3V；采样建议 ≥ 10 MHz |
| PulseView / sigrok | 录制与解码 | 推荐保存 `.sr` |
| 示波器（可选但更稳） | 确认电压与边沿 | 电压未明时优先 |
| 微型测试钩 / 杜邦线 | 接到 PCB 测试点 | 可临时焊细线 |
| 10kΩ 电阻（可选） | 串联限流保护 | 不能把 24V 变成安全电平 |

### 3.1 推荐硬件：nanoDLA

本仓库**不内嵌**分析仪固件/文档。抓包阶段推荐使用开源逻辑分析仪 **[nanoDLA](https://github.com/wuxx/nanoDLA)**（FX2 / PulseView 驱动 `fx2lafw`，最高约 24 MHz 采样）：

- 项目主页：<https://github.com/wuxx/nanoDLA>
- 上位机：PulseView（sigrok）；Windows 需用 Zadig 装 WinUSB；macOS 一般即插即用
- 与本桌接线：分析仪只接 `GND` / `CLK` / `DAT`，**不接**面板 `3.3V`

本桌优先从面板 PCB 测试点抓，不必先做复杂 RJ45 分线器：

| 丝印 | 接分析仪 |
|---|---|
| GND | GND |
| CLK | CH0 |
| DAT | CH1 |
| 3.3V | **不接** |

## 4. Phase 0 工作流

```text
断电导通 → 通电测压 → 接分析仪旁路监听 → 分场景录制
    → 判协议类型 → 找按键差分 → 找高度字段 → 写笔记
```

### 4.1 断电：针脚映射

桌子断电，必要时拔下 RJ45。用万用表蜂鸣档确认：

| PCB 测试点 | RJ45 针脚 | 线色（仅供参考，以实测为准） |
|---|---|---|
| 3.3V | pin 1 | 红 |
| CLK | pin 2 | 白 |
| GND | pin 3 | 绿 |
| DAT | pin 4 | 黑 |

同时检查：

- 各针脚之间是否意外短路。
- 面板按键是否直接短接到某根 RJ45 线（若是，可能是模拟电阻矩阵，不是数字协议）。

把结果填进文末「记录模板」。

本桌原厂面板断电并完全断开后，万用表实测：

```text
3.3V ↔ CLK = 1.99 kΩ
3.3V ↔ DAT = 1.99 kΩ
```

两个方向读数一致，说明原厂面板为 CLK/DAT 各提供一只约 `2 kΩ` 的外部上拉。

### 4.2 通电：电压确认

1. 恢复原厂面板与主机连接，通电。
2. 黑表笔接疑似 GND，红表笔依次测 `3.3V` / `CLK` / `DAT`。
3. 记录空闲电压与按键瞬间电压。

判断参考：

| 现象 | 可能含义 |
|---|---|
| 固定约 3.3V | 供电 |
| 固定约 0V | GND |
| 空闲稳定，按键后出现脉冲串 | 数字通信 |
| 两线电压反向变化 | 差分总线（本桌不太像，但仍要排除） |
| 按不同键得到不同稳定电压 | 电阻分压按键 |

**只有确认 CLK/DAT 峰值在分析仪安全范围内，才进入下一步。**

### 4.3 接线（旁路监听）

```text
升降桌主机
    │ 原 RJ45
    ▼
原控制面板
 ├── GND ───── 逻辑分析仪 GND
 ├── CLK ───── 逻辑分析仪 CH0
 ├── DAT ───── 逻辑分析仪 CH1
 └── 3.3V      不接分析仪电源
```

PulseView 建议起步参数：

| 参数 | 建议值 |
|---|---|
| 采样率 | 10 MHz（边沿很密再提到 24/48 MHz） |
| 时长 | 单次 20–60 s |
| 通道 | D0=CLK，D1=DAT |
| 触发 | 先用按键操作人工开录；必要时改 CLK 边沿触发 |

### 4.4 ESP32 替换面板时的电气差异

上面的旁路抓包保持原厂面板在线，因此面板上的两只约 `2 kΩ` 上拉也在线。该环境只能证明
协议和电平范围，**不能证明拔掉面板后 CLK/DAT 仍有有效上拉**。

Phase 1 用 ESP32 完全替换原厂面板时，应补回：

```text
红线 3.3V ── 2 kΩ（可用 2.2 kΩ）── 白线 CLK / GPIO4
红线 3.3V ── 2 kΩ（可用 2.2 kΩ）── 黑线 DAT / GPIO5
绿线 GND ─────────────────────────── ESP32 GND
```

红线不得直接连接 ESP32 `3V3`；ESP32 仍由 USB 独立供电。万用表在活动总线上读到的 CLK/DAT
是占空比平均值，不能代替逻辑分析仪对高电平、ACK 和数据字节的检查。

## 5. 抓包场景清单

每项最好重复 3 次。文件名建议如下，统一放进 `captures/`（目录后续创建）。

| 序号 | 操作 | 建议文件名 | 关注点 |
|---|---|---|---|
| 1 | 上电后静置 20–30 s | `idle.sr` | 有无心跳 / 轮询 |
| 2 | 单击上升 | `up_click.sr` | 按下帧 |
| 3 | 长按上升约 2 s 后松开 | `up_hold.sr` | 保持 / 松开 |
| 4 | 单击下降 | `down_click.sr` | 与上升差分 |
| 5 | 长按下降约 2 s 后松开 | `down_hold.sr` | 停止可靠性 |
| 6 | 单击档位 1 | `preset_1_click.sr` | 前往命令 |
| 7 | 长按档位 1 保存 | `preset_1_hold.sr` | 保存命令 |
| 8 | 档位 2/3/4 同上 | `preset_n_*.sr` | 档位编码 |
| 9 | 从低到高全程上升 | `full_up.sr` | 高度字段是否递变 |
| 10 | 从高到低全程下降 | `full_down.sr` | 同上 |
| 11 | 运动中松手 | `release_while_moving.sr` | 停止语义 |
| 12 | 到达目标后静置 | `after_arrive_idle.sr` | 停止后总线行为 |

录制时在旁边记一笔：面板显示高度、按键时刻、是否真正开始运动。

## 6. 怎么从波形里读协议

### 6.1 先判谁是主机

| 观察 | 推断 |
|---|---|
| 静置时 CLK 持续有脉冲 | 更像主机在轮询，或持续广播状态 |
| 仅按键时才有 CLK | 更像面板主导发时钟 |
| 桌子运动时 DAT 持续变化 | 很可能含实时高度或状态 |

本项目更倾向「主机出 CLK、DAT 半双工」假设，但以抓包为准。

### 6.2 同步串行的基本读法

CLK 给节拍，DAT 给比特。需要确认：

- 在 CLK **上升沿** 还是 **下降沿** 采样 DAT
- MSB first 还是 LSB first
- 一帧多少 bit（8/16/24/32 都很常见）
- 帧与帧之间的空闲间隔

粗算比特时间：量相邻 CLK 脉冲周期。例如周期约 10 μs → 约 100 kHz 时钟量级。

### 6.3 优先尝试的解码器

在 PulseView 中可先试：

1. **I²C**（CLK→SCL，DAT→SDA）  
   若能稳定出现 START / 地址 / ACK / STOP，再深挖。  
   注意：长 RJ45 上跑 I²C 不常见，但低速私有用法仍可能存在。
2. **SPI**（仅作对照；本桌通常没有独立 CS/MISO/MOSI 全套）
3. 解不出标准协议 → 按 **自定义同步串行** 手工切字节

### 6.4 差分对比法（找命令）

固定其他条件，只改变一个操作：

```text
idle 字节流
  vs
up_click 字节流
  → 差异位/字节 ≈ 上升相关
```

同理对比：

- up vs down
- click vs hold vs release
- preset1 vs preset2
- 高度 70.0 → 70.1 → 70.2 时哪几个字节在加

重点标出可能字段：

| 字段类型 | 怎么认 |
|---|---|
| 固定头/尾 | 几乎每帧相同 |
| 按键状态 | 仅在按键瞬间变化 |
| 高度 | 随显示值单调变化 |
| 计数器 | 每帧 +1 |
| 校验 | 改任意数据位后该字段跟着变 |
| 心跳 | 静置仍周期性出现 |

### 6.5 按下 / 松开不要漏

长按往往不是一条“持续上升”魔法命令，而是：

```text
上升按下
（可选）保持 / 心跳
上升松开
```

Phase 1 必须先搞清 **松开/停止**，再追求长按手感。漏掉松开有持续跑桌风险。

### 6.6 档位保存在哪

长按保存档位 1 之后：

- 若后续「单击档位 1」帧内容变了 → 面板侧可能带具体高度
- 若单击帧不变，但桌子仍去新高度 → 主机侧保存预设更可能

把结论写进协议笔记，直接影响网关要不要本地存档位。

## 7. 高电压时的临时保护（仅应急）

若实测超过分析仪耐压，**先停**，改用示波器。若确认是较高幅值的单端逻辑且必须临时看边沿，可用分压（示例，需按实测重算）：

```text
信号 ── 68kΩ ──┬── 分析仪输入
               │
              10kΩ
               │
              GND
```

注意：

- 分压会改变边沿与阈值，只用于“看有没有信号”，不适合精确解码。
- 差分总线不能这样当单端硬接。

更稳妥仍是：示波器确认 → 合适电平转换后再用分析仪。

- [ ] RJ45 ↔ PCB 测试点映射表
