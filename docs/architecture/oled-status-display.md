# 0.91 英寸 OLED 状态屏

| 项 | 内容 |
|---|---|
| 文档编号 | DG-HW-004 |
| 日期 | 2026-08-14 |
| 状态 | 固件已实现，待真机显示验收 |
| 屏幕假设 | SSD1306、128×32、I2C、地址 0x3C 或 0x3D |

## 1. 接线

OLED 与 TOF050C、TOF400C 共用现有外设 I2C 总线：

![YD-ESP32-S3 与 0.91 英寸 OLED 接线](images/oled-wiring.png)

| OLED | ESP32-S3 | 说明 |
|---|---|---|
| GND | GND | 必须与 ESP32、ToF 外部电源共地 |
| VCC | 3V3 | 不接外部 5V，避免 SDA/SCL 被上拉到 5V |
| SCL | GPIO10 | 共享 I2C1 时钟 |
| SDA | GPIO11 | 共享 I2C1 数据 |

OLED、两块 ToF 模块都可能带有 I2C 上拉电阻。真机接线后若出现测距丢帧、
OLED 闪烁或总线错误，应断电测量 SDA/SCL 到 3V3 的等效上拉电阻，而不是
先通过降低 Brownout 门限或增加软件重试掩盖电气问题。

## 2. 页面

屏幕每 4 秒轮播以下页面：

1. 大字显示桌面高度和右侧墙面间距。
2. 显示桌子运动状态、TOF050C/TOF400C 在线状态和童锁。
3. 显示 Wi-Fi 模式、IP 地址、BLE 当前连接数和 Bond 数量。

运动期间轮播暂停，优先显示 `UP`、`DOWN` 或 `PRESET` 与实时高度。任一
ToF 数据无效或超过 1 秒未更新时，每四个页面周期插入一次 `SENSOR OFFLINE`
告警；告警不会触发或禁止桌子运动。

## 3. 软件边界

- `desk_peripheral_i2c` 是 GPIO10/11 总线的单一所有者。
- `desk_tof` 与 `desk_oled` 只注册各自的 I2C Device Handle。
- OLED 自动探测 `0x3C`、`0x3D`，缺失时只记录一次日志并退出显示任务。
- OLED 使用轻量 ASCII 字模，不引入完整图形库，也不保存业务状态。
- 页面只读取 `desk_core`、`desk_tof`、`wifi` 和 `ble` 快照，不参与控制。

## 4. 真机验收

- [ ] 冷启动时日志出现 `SSD1306 128x32 ready at 0x3c` 或 `0x3d`。
- [ ] 高度与右侧间距和 Web 页面一致，未知值显示 `--.-`。
- [ ] 三个页面按 4 秒周期轮播，没有残影、错位或左右镜像。
- [ ] 上升、下降和档位运动时立即切换为运动页面，停止后恢复轮播。
- [ ] 拔掉任一 ToF 后显示离线告警，Web、BLE、STOP 和手动升降不受影响。
- [ ] 不接 OLED 启动时只出现一次缺失日志，两颗 ToF 仍持续正常采样。
- [ ] OLED 与 ToF 同时运行 30 分钟，无 Brownout、I2C 超时或显示闪烁。

完成以上检查前，只能确认固件构建和主机页面测试通过，不能把 OLED 标记为
真机验收完成。
