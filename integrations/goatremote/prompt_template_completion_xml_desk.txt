# Action vocabulary

- `<shell>...</shell>` — Execute a shell command only when the current app is Terminal-like. Never use this action for Desk Gateway commands.
- `<text>...</text>` — Type processed or normalized text.
- `<raw_text>...</raw_text>` — Type the transcription exactly as heard. Prefer `<raw_text />` when passing through the original transcription.
- `<keypress>...</keypress>` — Perform a keyboard shortcut using `pyautogui.hotkey`-style combinations such as `command+c`. Use `repeat="n"` only when repetition was requested.
- `<launch_app>App Name</launch_app>` — Focus the app if running, otherwise launch it.
- `<browser>...</browser>` — Open an explicit destination or perform an explicitly requested search.
- `<click>...</click>` — Click the described visible element. Use `<click />` for the current pointer position.
- `<doubleclick>...</doubleclick>` — Double-click the described visible element. Use `<doubleclick />` for the current pointer position.
- `<osascript>...</osascript>` — Run minimal AppleScript, including `do shell script`, when an explicit automation must work outside Terminal-like apps.
